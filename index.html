How to connect

  1. Use the Join server button above — it is filled in from the live status.
  2. Or open the TF2 console with ~ and paste:
connect <ip>:<port>

The address changes every time the server restarts, so the page rebuilds it from the running server. If the page is stale, ask in Discord for the current IP. You can also search gabes little server in the server browser.

House rules

  • Do not cheat, exploit, or crash the server. Random effects are chaos, not an excuse.
  • No chat or mic spam, no slurs, no harassing people.
  • Respect admins — their call is final, argue in Discord afterwards.
  • MvM: do not grief the team. Buying nothing and idling in spawn is griefing.
  • PLR: play the objective at least sometimes. Spawn camping the enemy cart all round is boring for everyone.
  • Bug reports and plugin ideas go in Discord, not in chat mid-round.

FAQ

Why is my screen upside down / grey / on fire?

Random effect. It goes away on its own. It is not a bug, and no, you cannot opt out for one round.

The server is not showing as online. What now?

Only one mode runs at a time. If nothing is online the machine is probably down or restarting — the Discord is where it gets announced. The status bar on this page refreshes every 30 seconds.

The IP on this page is wrong.

The address is generated fresh on each server start and pushed here automatically. Give it half a minute after a restart; if it is still wrong, ping Discord.

Can I get admin?

Admins are picked, not requested. Be around, be useful, do not ask every day.

Can I suggest an effect or a map?

Yes — post it in Discord. The chaos plugin has a huge effect list, and both servers have limited map pools.

Why are there bots?

Bots fill empty slots so the server is not dead while people join. Real players take their place as they connect.

Everything happens in Discord

Server IPs, restarts, map votes, plugin updates, and the people you just played with. It is the only place updates get announced.
